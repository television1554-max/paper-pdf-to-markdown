PDF 轉 Markdown

英文論文專用。每頁用 Nougat 在本機 GPU 辨識，再與 PDF 文字層逐頁核對數字，疑似漏掉表格的頁面會附上原始文字。

把 PDF 拖到這裡，或點一下選擇檔案 可一次選取多個檔案，加入後立即依序轉換

    尚未加入檔案

    轉好的檔案會自動存到輸出資料夾，關掉網頁也不會消失。同名檔案會覆蓋舊的結果。

    結果以 <!-- page N --> 標記頁碼。標有「⚠ 第 N 頁」的地方，GPU 辨識可能漏掉表格或數字，後面附的原始文字才是準的；[MISSING_PAGE…] 表示掃描檔該頁辨識失敗，可改用 base 模型重轉。

    Nougat 偶爾會在看不清處產生看似合理但錯誤的內容。引用任何數字前，請回到 PDF 核對。圖片不會轉出。
